# Nihar Dugade Portfolio Site

Static recruiter portfolio for data engineering, analytics, BI, and junior data science roles.

## Files

- `index.html` - portfolio content and structure
- `styles.css` - responsive professional styling
- `assets/Nihar-Dugade-Resume.pdf` - downloadable resume

## Local Preview

Open `index.html` in a browser.

## Publish Options

The quickest path is GitHub Pages:

1. Create a public repository named `portfolio` or `nihardugade.github.io`.
2. Upload `index.html`, `styles.css`, and the `assets` folder.
3. In GitHub, go to `Settings > Pages`.
4. Set source to the repository branch and root folder.
5. Add the published URL to LinkedIn, your resume, and job applications.
